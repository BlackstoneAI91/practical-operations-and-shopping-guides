Hotel Linen Par-Level Worksheet: Rooms, F&B and Spares

Published by Sinar Saredah Sdn Bhd.

A worked example for calculating hotel linen par levels across room types, food and beverage outlets and spare stock, with a fill-in worksheet and a handoff checklist for Sarawak accommodation operators.

What a par level actually answers

A par level is the quantity of each linen item a property keeps on hand so that rooms and outlets can be made up without waiting for laundry to return. It is not a single number pulled from a manual. It is the result of four inputs: how many items each room or table set needs, how often those sets are changed, how long a laundry cycle takes from bag-out to clean return, and how much buffer the property wants against a late or short return.

The worksheet below treats those inputs as separate lines so that a manager can see which one is driving the total. That matters because the usual instinct when linen runs short is to buy more stock, when the real constraint may be a slow turnaround, a sorting error or a missing count at the trolley.

Two practical notes before starting. First, count by item type, not by bundle: a double room set is a fitted sheet, a flat sheet, two pillowcases and a towel set, and each of those has its own replacement rhythm. Second, write the worksheet in pencil. Par levels move with occupancy, with outlet hours and with any change in laundry turnaround, so a figure set once and never revisited will drift away from what the property actually needs.

Step one: build the room-type demand table

Start with a simple table. Down the left side, list each room type the property sells, for example Standard, Deluxe and Family. Across the top, list each linen item that room type uses. In each cell, write the quantity used per made-up room.

A fictional example: a 40-room property has 20 Standard rooms, 15 Deluxe rooms and 5 Family rooms. A Standard room uses one fitted sheet, one flat sheet, two pillowcases and two bath towels. A Deluxe room uses the same plus two hand towels. A Family room uses two of each bed item and four bath towels. Multiply the per-room quantity by the number of rooms of that type to get the working set for a full house.

That gives the number of items in use at peak occupancy. It does not yet give a par level, because every item in use is also an item that will eventually be in the wash. The next step converts the working set into a circulating quantity.

Keep this table separate from the food and beverage table. Rooms linen is driven by checkouts and stayover service; outlet linen is driven by covers, table turns and service periods. Mixing them into one total hides which side of the property is short. If the property also runs a small function or meeting space, give it its own column rather than folding it into either table, so that a one-off event does not quietly consume room stock.

Step two: convert the working set into a circulating quantity

The circulating quantity is the working set multiplied by a turnover factor. The factor represents how many full sets must exist to keep the property supplied while one set is in use, one is in transit or being washed, and one is held clean as buffer.

A common starting heuristic, offered here as an author example rather than an industry standard, is a factor of three for a property with a reliable daily laundry cycle: one set on the bed, one set in the laundry pipeline, one set clean on the shelf. A property with a longer or less predictable cycle might use four. A property with a very short in-house cycle might use two and a half, though fractional factors should be rounded up per item.

Worked example using the fictional 40-room property: if the full-house working set is 400 bath towels, a factor of three gives a circulating quantity of 1,200 towels. That figure is the target holding across rooms, laundry pipeline and store. It is not a purchase order; it is the number the property is trying to keep whole.

Write the factor and the date beside it on the worksheet. When the laundry arrangement changes, the factor is the first thing to revisit, and a dated note makes that review easier to justify to an owner or finance colleague who asks why the linen budget moved.

Step three: add F&B outlet demand

Food and beverage linen behaves differently from room linen. Tablecloths, napkins and service cloths are consumed by covers and by service periods rather than by checkouts, and a single busy evening can pull more linen than a whole floor of rooms.

Build a second table with one row per outlet and one column per linen item. For each outlet, record the number of tables, the number of covers in a typical service, and how many times a table is reset in an evening. Multiply to get the outlet's working set for one service, then multiply by the number of services the outlet runs before laundry returns.

A fictional example: a hotel restaurant with 20 tables runs two dinner services between laundry collections. If each table uses one cloth and four napkins per service, the outlet needs 40 cloths and 160 napkins for those two services, plus a clean buffer for the next service. A banquet space should be calculated separately, using the largest expected event rather than the average, because banquet linen is usually pulled in a single block.

Keep outlet linen in its own bags and its own count sheet. When room and outlet linen are mixed in one bag, the count at return becomes unreliable and the outlet usually absorbs the shortfall.

Step four: size the spare stock deliberately

Spare stock is the part of the par level that absorbs the unexpected: a stained item pulled from service, a short return, a damaged piece, or a sudden increase in occupancy. It should be a stated percentage of the circulating quantity, chosen on purpose rather than left as whatever happens to be on the shelf.

A workable approach is to set spares per item type. High-wear items such as pillowcases and bath towels may warrant a larger spare percentage than flat sheets, because they are replaced more often. Write the percentage beside each item and calculate the spare quantity from the circulating figure, rounding up.

Then separate the spare stock physically from the working stock. If spares sit in the same stack as daily issue, they are consumed silently and the property discovers the gap only when a busy weekend arrives. A labelled shelf or a closed cabinet with a simple count sheet is enough.

Record damaged and retired items on the same sheet. A towel that is withdrawn from service reduces the par level until it is replaced, and a worksheet that ignores withdrawals will overstate what the property actually holds.

A fill-in worksheet you can copy

The worksheet below condenses the four steps into one page. Copy it into a spreadsheet or a printed form and complete it item by item.

Section A, room demand: for each room type, list rooms, items per room and the working set. Section B, outlet demand: for each outlet, list tables, items per table, services between collections and the working set. Section C, circulating quantity: multiply each working set by the turnover factor and record the factor and its date. Section D, spares: record the spare percentage per item, the calculated spare quantity and the physical storage location. Section E, current holding: count what is actually on shelves, in the pipeline and in rooms, and compare it with the target. Section F, actions: note each gap, who owns it and the date it will be reviewed.

A fictional filled line might read: bath towel, working set 400, factor 3, circulating 1,200, spare 10 percent, spare quantity 120, target holding 1,320, current holding 1,180, action to review with the laundry provider.

Keep the completed worksheet with the property's other linen records. Where linen is handed to an outside provider, the count at handover and the count at return are the evidence that makes the worksheet useful, so agree the counting method in writing before the first collection.

Handoff notes for properties using an outside laundry

A par-level worksheet only holds if the handoff is consistent. Three habits make the difference.

First, count at bag-out and count at return, using the same item names on both sheets. A bag that leaves with 60 items and returns with 57 should be queried the same day, not at month end.

Second, keep room linen and outlet linen in separate, labelled bags. This protects the outlet count and makes it easier to trace a shortfall to a specific collection.

Third, agree in advance how stained or damaged items are handled, so that a withdrawn item is recorded rather than simply disappearing from the count.
