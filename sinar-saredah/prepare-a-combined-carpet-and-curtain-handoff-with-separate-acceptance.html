Prepare a Combined Carpet and Curtain Handoff with Separate Acceptance Steps

Published by Sinar Saredah Sdn Bhd.

A practical guide for Sarawak households, accommodation operators and venue managers who send carpets and curtains for cleaning together but need separate access, return and placement sign-offs for each item type.

Why one collection needs two acceptance tracks

Sending carpets and curtains out in the same collection feels efficient, but the two item types behave differently once they leave the room. A carpet is usually tied to a floor zone and a room that must stay usable or be closed. Curtains are tied to a window, a rail and a set of panels that must come back in the right order. If you accept both under a single signature, you lose the ability to say which item was checked, by whom, and against what reference.

Before the collection, split the handoff into two tracks. Track one covers floor coverings: which rooms, which zones, whether the item is fixed or movable, and who can authorise access. Track two covers window textiles: which windows, how many panels per window, how they are labelled, and who confirms placement on return. Each track gets its own acceptance step, its own named reviewer and its own record.

This is a procedural split, not a cleaning instruction. You are deciding who checks what, not how anything is treated. Build the pre-collection worksheet: two columns, one visit

Use a single worksheet with two clearly separated columns so the collection stays one visit but the review stays separate. In the carpet column, record a zone name the team already uses (for example, function room floor, lobby runner, guest room floor), whether the item is fixed or movable, and the name of the person who can open that space. In the curtain column, record the window reference, the number of panels, any existing label on each panel, and the name of the person who will confirm placement later.

Add a shared header for the visit itself: date, the person handing over, the person receiving, and the written confirmation reference. Keep the two columns from borrowing each other's fields. A room access note does not belong in the curtain column, and a panel count does not belong in the carpet column.

A short worked example: a small guesthouse in Sarawak sends two movable entrance runners and the curtains from four rooms. The runner column lists two items and one access contact. The curtain column lists four windows, eight panels and eight existing labels. The header records one handover. Nothing is merged. Assign roles: access keeper, return checker, placement confirmer

Three roles keep the two tracks honest, and one person can hold more than one role as long as the worksheet says so.

The access keeper controls rooms and openings. This person confirms which floor zones can be entered, when, and by whom, and is the only one who changes an access window. The return checker receives items back and compares counts, labels and written remarks against the worksheet. The placement confirmer is the person who later confirms that each curtain panel is back at the window it belongs to and that each carpet is back in its zone.

Separating the return checker from the placement confirmer matters when rooms are busy. A return checker can sign for eight panels at the loading point without claiming they are on the right rails. The placement confirmer does that second check in the room. Write both names on the worksheet before collection, not after.

For commercial premises, the same three roles map onto a building contact, a receiving officer and an area owner. If your site also uses scheduled commercial cleaning, keep that schedule separate from this handoff so the two records do not overwrite each other. Write the carpet acceptance step as a zone check

The carpet acceptance step answers one question: is this the item from this zone, and is the zone ready to be used again? Keep it to four lines.

Line one: zone name and item description as written on the worksheet. Line two: count, for movable items, or a single confirmation for fixed coverings. Line three: any remark the provider recorded, copied exactly rather than paraphrased. Line four: the decision, chosen from a short list such as accepted, accepted with a note, or held for a written question.

Do not fold appearance judgements into this step. If a reviewer wants to raise something about how the item looks, that becomes a written question routed through the agreed channel, not a verbal note at the door. The acceptance step records identity, count and decision; it does not certify a result.

A fictional example: a venue manager accepts two entrance runners back into storage and marks both as accepted with a note that one label is faded. The note is copied from the provider's remark, not invented. The room itself is reopened only after the access keeper confirms the floor zone is clear. That keeps the carpet decision and the room decision in different hands.

Write the curtain acceptance step as a panel check

The curtain acceptance step is a matching exercise, so build it around labels rather than memory. For each window, list the panel labels you recorded before collection and leave a blank beside each one for the return check. The return checker ticks each label as it is counted and writes any mismatch as an open item.

The placement confirmer then works room by room, not pile by pile. For each window, they confirm the panel count matches and that the label on each panel corresponds to that window. They do not need to describe how the panel is attached; they only confirm identity and location. If a panel cannot be matched, it is held and recorded, not guessed into place.

Keep a separate line for any panel that arrives without its label. That line is the most useful part of the record later, because it shows the question was raised at the right moment. A short note such as "one panel unlabelled, held for written confirmation" is enough. The same discipline applies to other labelled textile items you may send in the same period, such as a wedding gown cleaning order or soft toy cleaning, where identity matters as much as condition.

Close the handoff with a two-signature summary

End the process with a one-page summary that carries both tracks but keeps their signatures apart. The summary should show the collection reference, the two acceptance decisions, the names of the return checker and placement confirmer, and a short list of open items with an owner and a next step for each.

Two signatures, not one, is the point. The carpet line is signed by whoever holds the zone decision. The curtain line is signed by whoever holds the placement decision. If the same person holds both roles, they still sign twice, because the two checks happened at different moments and answer different questions.

Keep the summary with your other service records so it can be read alongside the written confirmation and any invoice. The brand's terms note that they apply together with quotations, invoices, branch notices, written service confirmations and related policies, which is a useful reminder to store these documents as one set rather than scattered across inboxes.

As an author heuristic, allow roughly ten minutes per zone for the carpet check and a few minutes per window for the curtain check. Treat those as planning examples only, not as standards, and adjust them to the size of your site.

Common gaps to catch before the collection leaves

Run this short pre-collection review so the two tracks do not collapse into one.

First, check that every carpet zone has a named access keeper and every curtain window has a named placement confirmer. Second, check that panel labels are written down, not photographed and forgotten. Third, check that the worksheet has one header and two columns, with no field borrowed across. Fourth, check that any remark from the provider is copied exactly. Fifth, check that open items have an owner before the items leave, not after they return.

A fictional example of a gap: a hotel sends six curtains and one lobby runner, but the worksheet lists only five windows. The return checker counts six panels against five windows and cannot close the line. The fix is not to add a window after the fact; it is to record the sixth panel as an open item and ask for written confirmation of which window it belongs to.
