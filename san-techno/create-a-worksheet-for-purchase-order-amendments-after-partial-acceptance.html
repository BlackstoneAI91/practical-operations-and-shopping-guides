Create a Worksheet for Purchase-Order Amendments After Partial Acceptance

Published by San Techno.

A practical worksheet for Singapore procurement teams that need to amend a purchase order after some items have already been accepted, separating settled lines from open lines and cross-checking which approval references still apply.

Why partial acceptance changes the amendment job

A purchase order that has been partly accepted is no longer a single clean commitment. Some lines are settled: goods arrived, documents were checked, acceptance was recorded. Other lines are still open, and those are the only ones an amendment should normally touch. The risk is that a well-meant amendment quietly rewrites the settled part of the order, or that a new approval reference is applied to lines that were already closed under an older one.

This worksheet is written for procurement teams in Singapore who source semiconductor materials, solar materials and reclaimed silicon, where a single order can mix wafer lots, packaging items and documentation milestones. It is an administrative tool, not contract advice. Its job is to make the amendment readable: what was settled, what is still open, what changes, and which approval numbers still apply after the change.

San Techno Pte Ltd is a Singapore-based company working across semiconductor and solar materials, silicon recovery, specialized power module development and botanical extracts under the ST GREEN brand, so orders in this space can span very different product families. That variety is exactly why a worksheet helps: the amendment has to be legible to a reader who did not raise the original order.

Set up the worksheet header before touching any line

Start with a header block that identifies the amendment itself, not just the order. Record the purchase order number, the amendment number, the date the amendment is drafted, the person drafting it and the person who will approve it. Add the original order date and the date of the last recorded acceptance, because the gap between those two dates tells a reviewer how much has already happened.

Then add a short purpose line: one sentence saying what the amendment is for. Examples of a purpose line, all fictional: "Reduce the open quantity on line 4 following a partial delivery," or "Correct the document reference on line 7, which remains open." A purpose line that names a line number keeps the amendment from drifting into a general rewrite.

Finally, add a status field with three values only: draft, approved, issued. Anything not marked issued should not be treated as the current version of the order. Keep the previous version of the worksheet alongside the new one so a reviewer can see what changed between drafts.

Separate settled items from open items

This is the core of the worksheet. Build a table with one row per order line and a status column that uses plain words: settled, open, or cancelled. A line is settled when acceptance has been recorded against it. A line is open when quantity, date or documentation is still outstanding. A line is cancelled when it was withdrawn before acceptance.

Only open lines belong in the amendment body. Settled lines should appear in a reference block above the amendment, with their accepted quantity and acceptance date, so the reader can see they exist and are not being changed. If an amendment genuinely needs to touch a settled line, mark it clearly as an exception and route it for a separate approval rather than folding it into the routine amendment.

For teams handling mixed orders, this separation matters most where product families differ. An order might include semiconductor materials alongside items from a silicon recovery or wafer reclaim arrangement, and the acceptance evidence for each can sit with different people. The worksheet does not need to explain the products; it needs to show which lines are closed and which are not.

Make the amendment readable line by line

For each open line, use a fixed set of columns so two amendments can be compared without guesswork. A workable set is: line number, item description as written on the original order, original quantity, quantity already accepted, open quantity, original requested date, revised requested date, and the reason for the change.

Keep the item description exactly as it appears on the original order. Do not paraphrase it in the amendment, because a paraphrase creates a second description of the same item and a reviewer then has to decide which one governs. If the original description was unclear, note that as a separate query rather than silently rewriting it.

Use a change-type column with a small controlled list: quantity, date, document reference, or other. A controlled list stops the amendment from becoming a narrative. Where the change is a document reference, record the old reference and the new reference side by side so the reader can see the substitution.

Add a short note column for anything a reviewer must know, such as a pending confirmation from the supplier. Keep notes factual and dated. Avoid opinions about the supplier in this column; the worksheet is a record, not a review.

Cross-check which approval numbers still apply

An amendment after partial acceptance often inherits approvals from the original order, but not always. Build a small approval block with one row per approval reference and four columns: reference number, what it approved, the date it was given, and whether it still applies to the amended scope.

Use three values in the last column: applies, superseded, or needs review. An approval applies when the amended scope sits inside what was originally approved. It is superseded when a later approval replaced it. It needs review when the change moves outside the original scope, for example a quantity change large enough that the original approval no longer describes the commitment.

This block is where most amendment errors surface. A buyer may assume the original approval covers a revised date, when in fact the approval was tied to a specific delivery window. Writing the assumption into a column forces someone to check it. Where an approval needs review, name the role responsible for the review, not a person, and set a target date for the decision. Treat any target date as an example of good practice rather than a rule.

A worked fictional example

Consider a fictional order with five lines. Lines 1 and 2 were accepted in full and are settled. Line 3 was partly accepted: 40 of 60 units recorded, leaving 20 open. Line 4 is open with no delivery yet. Line 5 was cancelled before acceptance.

The amendment should reference lines 1 and 2 in the settled block with their acceptance dates, leave line 5 in the cancelled block, and carry only lines 3 and 4 into the amendment body. For line 3, the change type is quantity, with the open quantity restated as 20. For line 4, the change type might be date, with the original requested date and the revised requested date shown side by side.

The approval block might show one reference that applies to line 3 because the reduced open quantity sits inside the original approval, and a second reference marked needs review for line 4 because the revised date falls outside the window the original approval described. The reviewer can then see, in one glance, that only one approval question is genuinely open.

This example is invented to show the layout. It is not a description of any real order or supplier arrangement.

Close the amendment and hand it over cleanly

Before the amendment is issued, run a short checklist. Confirm that every settled line appears in the reference block and none appear in the amendment body. Confirm that every open line has a change type and a reason. Confirm that every approval reference has a value in the applies column. Confirm that the purpose line names the lines being changed. Confirm that the previous version of the worksheet is retained.

Then record the handover. Note who received the issued amendment, on what date, and which internal records were updated as a result. If the amendment touches documentation rather than quantity or date, note which document reference changed and where the current version is held.

For teams that also work with San Techno on power module development, keep the amendment worksheet separate from any technical discussion. The company's power-module programme addresses heat movement, package stability and reliable operation under repeated electrical and thermal loading, and detailed architecture, materials, dimensions and assembly processes remain confidential. None of that belongs in a purchase-order amendment; the worksheet should carry only the commercial and documentary fields described above.
